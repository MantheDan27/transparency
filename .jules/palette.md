## 2026-09-25 - Adding dynamic tooltips to JS-managed disabled elements
**Learning:** When elements like buttons have their `disabled` state toggled dynamically by JavaScript, static `title` tooltips added in the HTML intended to explain the disabled state will erroneously persist when the element is re-enabled. Additionally, native `title` attributes on disabled buttons work natively in `device-monitor-desktop` because `.btn:disabled` does not set `pointer-events: none`.
**Action:** Always use JavaScript to dynamically set or remove the `title` attribute inside the same event listener that manages the `disabled` state, ensuring the tooltip only appears when the element is disabled.
